# Vuizcomm Frontier Command

Android strategy sandbox inspired by regional politics and nation simulation.

Current features:
- Offline Android game with no server dependency.
- Population, treasury, influence, stability, industry and diplomacy.
- Vuizcomm-style four-territory map.
- Advance simulation and diplomacy interactions.
- JSON save state using SharedPreferences.
- Android API 23+ with Java 17.
- GitHub Actions builds app-debug.apk automatically.

Build with JDK 17 and Gradle 8.7:
gradle assembleDebug

APK output:
app/build/outputs/apk/debug/app-debug.apk

Push to main, then download the Vuizcomm-Frontier-Command-debug artifact from GitHub Actions.

No proprietary NationStates code or assets are included.
